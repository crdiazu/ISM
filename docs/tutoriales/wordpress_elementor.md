# Tutorial Simple: WordPress y Elementor

## ¿Qué es y para qué sirve en el ISM?
WordPress es el sistema base de la página `ismchile.cl`. Elementor es el "constructor visual" que permite cambiar textos o fotos en la página sin saber programar. *Nota: Este trabajo suele hacerlo el desarrollador aliado, pero es bueno saber cómo hacer cambios rápidos.*

## Tutorial Básico

### 1. Entrar al Panel de Control (Dashboard)
1. Ve a `www.ismchile.cl/wp-admin` (o la URL que te haya dado el desarrollador).
2. Ingresa tu usuario y contraseña.
3. Verás el menú negro a la izquierda. Ese es el corazón de WordPress.

### 2. Editar un Texto con Elementor (Ej: Cambiar el mes de "Matrícula Gratis")
1. Ve a la página principal de `ismchile.cl` como si fueras un visitante normal (estando logueado).
2. Arriba verás una barra negra. Haz clic en **"Editar con Elementor"**.
3. La página cargará con un panel lleno de opciones a la izquierda.
4. Haz clic directamente sobre el texto que quieres cambiar (ej. "Noviembre 2025").
5. El panel izquierdo mostrará una caja de texto. Cambia el texto ahí (ej. a "Marzo 2026").
6. Abajo a la izquierda, dale al botón verde **"Actualizar"** (Update) para guardar.

### 3. Añadir Códigos de Seguimiento (Para Marketing)
Como encargado de marketing, a veces necesitarás poner un "Pixel" de Facebook o Google Tag Manager.
1. No modifiques el código fuente.
2. Normalmente el desarrollador instala un plugin (como *PixelYourSite* o *HFCM*).
3. Busca en el menú izquierdo de WordPress ese plugin, pega tu código (el ID de Facebook o Google) y guarda.

## Detalles Adicionales
- **Botón de WhatsApp y Chatfuel:** Si necesitas cambiar el número al que va el botón de WhatsApp, o apagar el widget de Chatfuel, pídele al desarrollador que te muestre en qué parte específica de Elementor o WordPress lo configuró, ya que suele estar en el "Header" (Cabecera) o "Footer" (Pie de página).
- **Copias de Seguridad:** Nunca borres páginas importantes o instales plugins raros sin preguntarle antes al desarrollador.
