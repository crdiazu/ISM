# Tutorial Simple: Kommo (CRM)

## ¿Qué es y para qué sirve en el ISM?
Kommo es el "embudo de ventas". Aquí llegarán todas las personas interesadas en los cursos (Leads). Sirve para que el equipo comercial sepa exactamente en qué estado está cada persona (¿Preguntó? ¿Está pensando? ¿Se matriculó?).

## Tutorial Básico

### 1. Conociendo el Pipeline (Embudo)
Al entrar a Kommo, verás columnas. Cada columna es una etapa. Por ejemplo:
- **Lead Nuevo:** Acaba de preguntar por WhatsApp o FB.
- **Contactado:** Ya le enviamos la info del curso.
- **En Seguimiento:** Le estamos preguntando si tomó una decisión.
- **Cerrado Ganado (Matriculado).**
- **Cerrado Perdido (No compró).**

### 2. Gestionar un Prospecto (Lead)
1. Cuando Make envíe un nuevo prospecto, aparecerá una "tarjeta" en la columna "Lead Nuevo".
2. Haz clic en la tarjeta. Verás su nombre, teléfono y curso de interés.
3. En la parte derecha, puedes escribir notas (ej: "Dice que hablará con su mamá para ver cómo pagar").
4. A medida que hablas con el prospecto, **arrastra la tarjeta** hacia la siguiente columna hacia la derecha.

### 3. Configurar Tareas (Para no olvidar a nadie)
1. Dentro de la tarjeta de un prospecto, abajo dice "Añadir tarea".
2. Elige "Llamar mañana" o "Escribir un WhatsApp el viernes".
3. Kommo te enviará una notificación cuando sea la hora. Es clave para el seguimiento.

## Detalles Adicionales
- **Automatizaciones Nativas:** Kommo permite cambiar un prospecto de etapa automáticamente si, por ejemplo, visita una página web específica.
- **Importancia Vital:** El CRM solo sirve si **todos** en ventas mueven las tarjetas y escriben notas. Si la información se queda en la cabeza del vendedor, el sistema falla.
