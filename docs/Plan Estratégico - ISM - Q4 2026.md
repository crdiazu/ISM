## 2. DETALLE DE CADA ETAPA

### ETAPA 1: Diagnóstico y Ordenamiento Operativo (Septiembre 2026)
* **Qué es:** Revisión completa del [[ecosistema_digital]] y físico del Instituto.
* **Qué se hace:**
  1. Crear correos institucionales (`secretaria@`, `marketing@`, `direccion@ismchile.cl`).
  2. Dar acceso al sitio web a quien corresponda (ver [[08-Roadmap-Antonia-Web]]).
  3. Desvincular cuentas personales que ya no corresponden (ver [[Traspaso de acceso]]).
  4. Dejar claro que cámaras y alarmas son tema de seguridad física.
  5. Verificar y actualizar credenciales de acceso (ver [[03-Checklist-Traspaso-Maestro]]).
  6. Firmar [[01-Acuerdo-de-Confidencialidad]] y [[02-Politica-de-Privacidad-SitioWeb]].

* **Qué se hace:**

  3. **Plataforma lista:** Chatbot y página web funcionando con control de pagos (ver [[ecosistema_digital]]).
