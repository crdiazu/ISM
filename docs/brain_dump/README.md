# Brain Dump (Volcado de Información)

Esta carpeta es un espacio **seguro y desordenado** para volcar ideas, transcripciones de reuniones, notas rápidas y fragmentos de código.

No te preocupes por el formato o la estructura al crear archivos aquí. El objetivo principal es **no perder ninguna información valiosa** durante la fase de descubrimiento y transferencia de conocimiento. Periódicamente, la información de esta carpeta se revisará, estructurará y moverá a los documentos principales (como el Roadmap o el Plan de Transferencia).

## ¿Qué poner aquí?
- Archivos `.txt` o `.md` con notas de llamadas.
- Pegar correos importantes.
- Ideas sueltas de automatizaciones en Make.
- Esquemas rápidos de campañas.
