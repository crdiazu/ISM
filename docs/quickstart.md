# Quickstart

## Prerequisitos

- Node.js (v18+)
- npm (v9+) o pnpm
- Git

## Pasos rápidos

1. **Clonar el repositorio**
   ```bash
   git clone <url-del-repositorio>
   cd "Instituto SM/ISM"
   ```
2. **Instalar dependencias**
   ```bash
   npm install   # o pnpm install
   ```
3. **Ejecutar en modo desarrollo**
   ```bash
   npm run dev
   ```
4. **Abrir el navegador** y navegar a `http://localhost:3000` (o el puerto indicado).

## Verificación

- La página de inicio debería mostrarse sin errores.
- Ejecuta los tests para confirmar que todo funciona:
  ```bash
  npm test
  ```
