# Contributing to ISM

Thank you for your interest in contributing to the **Instituto SM (ISM)** project! Please follow these guidelines to make the contribution process smooth and effective.

## How to Contribute

1. **Fork the repository** and clone your fork locally.
   ```bash
   git clone <your-fork-url>
   cd "Instituto SM/ISM"
   ```
2. **Create a new branch** for your work:
   ```bash
   git checkout -b my-feature-branch
   ```
3. **Make your changes** following the project's coding standards (see `SETUP.md` for tooling).
4. **Run tests** to ensure nothing is broken:
   ```bash
   npm test
   ```
5. **Commit** with a clear, concise message.
6. **Push** your branch and open a Pull Request targeting the `master` branch.

## Code Style
- Use **Prettier** for formatting. Run `npm run format` before committing.
- Follow **TypeScript** best practices used throughout the codebase.
- Keep lint warnings to a minimum.

## Issue Reporting
- Search existing issues before opening a new one.
- Provide a descriptive title and detailed description.
- Include steps to reproduce, expected behavior, and screenshots or logs when applicable.

## Review Process
- Maintainers will review your PR and may request changes.
- Once approved, the PR will be merged.

## Community
- Be respectful and constructive.
- Ask questions in the appropriate channels (issues, discussion board, etc.).

Happy coding!
